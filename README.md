# 천지다 차 주문 사이트

천지다의 차 상품을 살펴보고 장바구니에 담아 주문 정보를 남기는 정적 웹앱입니다.

## 사용 방법

1. 상품을 고르고 `담기`를 누릅니다.
2. 장바구니에서 `주문 정보 입력하기`를 누릅니다.
3. 주문 정보를 입력하고 동의한 뒤 주문을 접수합니다.

주문 정보는 서버가 아니라 주문한 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 지우면 주문 정보도 사라집니다.

## 내 컴퓨터에서 미리 보기

```powershell
pnpm install
pnpm exec vite --host 127.0.0.1 --port 4173
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다. GitHub Pages용 정적 파일은 다음 명령으로 `site/` 폴더에 만듭니다.

```powershell
pnpm build:pages
```

실제 운영 전에 예시 계좌번호와 연락처를 본인 정보로 바꾸세요.
